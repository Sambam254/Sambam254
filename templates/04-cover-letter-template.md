### CareerBoost Cover Letter Checklist (Internal)

| Element | Included? |
|---------|-----------|
| Personalized salutation (not "To Whom It May Concern") | ☐ |
| Research mention — specific company project/news/product | ☐ |
| "Hook" paragraph — 1 quantified achievement upfront | ☐ |
| Body — 2-3 bullet highlights connected to role requirements | ☐ |
| Personalized "why this company" paragraph | ☐ |
| Call to action (interview request) | ☐ |
| Total length ≤ 1 page | ☐ |
| No generic phrases ("I'm a hard worker") | ☐ |
| Keywords from job description naturally integrated | ☐ |

### Customization Tips
- Spend 10 min researching the company before writing
- Find the hiring manager's name on LinkedIn if possible
- Reference a real product, feature, or company value
- Connect each bullet in the cover letter to a specific requirement in the JD
- Never use a generic cover letter — it's worse than none
